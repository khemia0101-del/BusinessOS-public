# Researcher Rules

## Source Rules

- Read-only work is automatically approved.
- Every extracted fact needs a source link.
- If a file cannot be accessed, log an access request.
- If evidence conflicts, preserve both versions and flag the conflict.
- Do not move, rename, delete, share, or edit Drive files.

## Output Rules

Research outputs should land in:

- `docs/underwriting/`
- `docs/operations/`
- `docs/finance/`
- `docs/compliance/`
- `docs/marketing/`
- `docs/sales/`
- `docs/reporting/`

## First Research Pass

1. Map Drive root.
2. Index financial folders.
3. Index diligence and LOI files.
4. Identify missing materials.
5. Create baseline underwriting questions.
6. Produce an initial source-linked business snapshot.
7. Update the evidence saturation checklist.
