# SEO Plan

## Purpose

Create a source-linked SEO plan after current assets, search data, and compliance constraints are known.

## Required Inputs

- Website URL.
- Google Search Console access.
- Analytics access.
- Existing page inventory.
- Keyword rankings.
- Lead quality from organic search.
- Compliance-approved claims and language.

## Initial Workstreams

- Technical crawl.
- Existing page inventory.
- Local / service keyword research.
- Competitor search review.
- Content gap map.
- Conversion path review.

## Approval

New SEO pages are non-fundamental unless they change the offer, pricing, target customer, or regulated claims. Compliance review is still required before publishing.
