# Evidence Saturation Checklist

Final underwriting and final scaling plans should not be issued until this checklist is completed or each blocker is explicitly documented.

## Data Room

- [ ] Drive root mapped.
- [ ] Financial folders indexed.
- [ ] Legal/closing documents indexed.
- [ ] HR/owner schedule indexed.
- [ ] Operations/process documents indexed.
- [ ] Marketing/sales assets indexed.
- [ ] Compliance-sensitive documents indexed.

## Systems

- [ ] CRM identified.
- [ ] Website identified.
- [ ] Analytics identified.
- [ ] Search Console identified.
- [ ] Ads accounts identified.
- [ ] Social accounts identified.
- [ ] Email/SMS systems identified.
- [ ] Review platforms identified.
- [ ] Payment/billing systems identified.

## Baseline

- [ ] Revenue baseline.
- [ ] Gross margin baseline.
- [ ] Net margin baseline.
- [ ] Owner benefit / add-backs.
- [ ] Customer acquisition sources.
- [ ] Sales conversion flow.
- [ ] Operations bottlenecks.
- [ ] Customer friction.
- [ ] Employee friction.
- [ ] Compliance constraints.

## Output Standard

- [ ] Facts separated from assumptions.
- [ ] Source links included.
- [ ] Conflicts flagged.
- [ ] Missing data listed.
- [ ] Missing permissions requested.
- [ ] Confidence level stated.
