# Follow-Up System

## Purpose

Document and improve lead follow-up.

## Required Inputs

- CRM access.
- Lead source data.
- Current follow-up sequence.
- Contact policy.
- Conversion data by follow-up step.
- Compliance-approved messaging.

## Candidate Improvements

- Missed-call text.
- Speed-to-lead automation.
- No-show follow-up.
- Long-term nurture.
- Lost-lead reactivation.
- Sales rep task reminders.

## Guardrails

No automated customer communication should deploy without an approved ticket and compliance review.
