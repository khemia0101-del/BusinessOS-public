# Workstreams

Workstreams are autonomous operating threads that do not require approval unless they hit an approval boundary.

Use workstreams for:

- Read-only data-room indexing.
- Business understanding.
- Internal documentation.
- Profile creation.
- Underwriting preparation.
- Scaling-plan preparation.
- Missing-tool discovery.

Use tickets only when approval, permissions, external execution, deployment, spend, or rollback tracking is needed.
