# Organizational Drag Index

## Purpose

Score how much time, money, and coordination a workflow burns before value is created.

This is the practical version of "organizational drag." It feeds the Operational Inefficiency Radar.

## Score Dimensions

Score each from 1 to 10:

| Dimension | Meaning |
| --- | --- |
| Delay | How long the workflow waits before value is created |
| Human touches | How many people must touch it |
| Handoffs | How many system/person handoffs exist |
| Rework | How often the work must be corrected |
| Revenue drag | How directly delay hurts revenue |
| Customer friction | How much friction the customer feels |
| Error risk | How often mistakes happen |
| Automation fit | How much of it can be automated |

## Interpretation

- 1-3: low drag.
- 4-6: worth monitoring.
- 7-8: strong automation/simplification candidate.
- 9-10: urgent bottleneck.
