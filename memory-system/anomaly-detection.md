# Anomaly Detection

## Purpose

Use documented signals to spot things that look unusual, risky, or worth investigating.

## Anomaly Types

- Sudden drop in leads.
- Sudden drop in bookings.
- Increase in no-shows.
- Customer complaints repeating.
- Employee friction repeating.
- Referral partner activity drops.
- Campaign metrics change.
- CRM stages clog.
- Response time worsens.
- Costs rise without result.
- Same manual error repeats.
- A promised follow-up is missed.
- Compliance-sensitive language appears.

## Output Format

```txt
Anomaly:
Evidence:
First seen:
Severity:
Likely cause:
Suggested investigation:
Suggested action:
Owner:
```
