# Business Memory And Signal Ledger

## Purpose

Document everything that may affect revenue, operations, customers, employees, compliance, finance, strategy, or execution.

This is not record keeping for its own sake. Hermes needs durable signal to spot anomalies, inefficiencies, repeated problems, missed follow-ups, revenue leaks, compliance risk, and proactive opportunities.

## What To Document

- Meetings.
- Calls.
- Emails.
- Telegram messages.
- Sendblue/iMessage/SMS.
- Employee feedback.
- Customer complaints.
- Lead conversations.
- Vendor conversations.
- Partner/referral conversations.
- Internal decisions.
- Owner instructions.
- Failed automations.
- Campaign results.
- CRM notes.
- Calendar events.
- Support tickets.
- Sales calls.
- Discovery calls.

## Standard Fields

Every entry should capture:

- Date/time.
- Actor(s).
- Channel.
- Summary.
- Source/link.
- Tags.
- Follow-up needed.
- Owner.
- Due date if any.
- Related ticket/workstream/initiative.
- Risk/anomaly flag.

## Default Rule

If it happened and may affect the business, document it.
