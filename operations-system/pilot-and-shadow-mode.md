# Pilot And Shadow Mode

## Purpose

Test automations safely before they affect customers, leads, employees, money, or production systems.

## Shadow Mode

The automation runs alongside the current human process but does not take external action.

Compare:

- Automation decision.
- Human decision.
- Data used.
- Outcome.
- Error cases.

## Pilot Mode

The automation runs live on a small approved subset.

Pilot plans must define:

- Batch size.
- Eligibility.
- Stop conditions.
- Monitoring owner.
- Rollback.
- KPI.
- Customer/employee impact.

## Scale Criteria

Scale only when:

- Eval passes.
- Test/simulation passes.
- Compliance passes if needed.
- Pilot KPIs meet threshold.
- Error rates are acceptable.
- Stop/rollback is clear.
