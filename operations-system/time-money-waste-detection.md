# Time And Money Waste Detection

## Purpose

Detect recurring costs and labor that do not create proportional value.

## Waste Categories

- Manual work that software can do.
- Waiting time that slows revenue.
- Duplicate software.
- Duplicate data entry.
- Unused subscriptions.
- Rework caused by unclear process.
- Employee time spent on low-judgment tasks.
- High-cost labor doing low-value work.
- Leads/customers lost from slow response.
- Unmeasured campaigns.
- Reports no one uses.
- Meetings without decisions or follow-up.

## Required Output

For every waste finding:

- What is happening.
- Evidence.
- Cost/time estimate.
- Root cause.
- Proposed removal/automation/delegation.
- Risk of changing it.
- Pilot.
- KPI.
