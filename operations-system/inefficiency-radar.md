# Operational Inefficiency Radar

## Purpose

Spot things that burn money, burn time, slow revenue, create errors, or can be automated to perfection.

## Signals

- Leads waiting on employees.
- Manual data transfer.
- Repeated copy/paste.
- Slow response time.
- Repeated questions.
- Duplicate systems.
- Software nobody uses.
- Human review before basic qualification.
- Missed follow-ups.
- Manual report building.
- Manual appointment scheduling.
- Manual customer status updates.
- Unclear ownership.
- Bottlenecks around one person.
- Frequent exceptions.
- High no-show or drop-off.

## Scoring

| Factor | Meaning |
| --- | --- |
| Time burned | Human hours lost |
| Money burned | Direct cost or lost revenue |
| Delay cost | Revenue slowed by waiting |
| Automation fit | Can software handle it reliably |
| Error risk | Mistakes caused by manual process |
| Customer impact | Friction or experience damage |
| Compliance/data risk | Sensitive handling concern |

## Default Rule

Any repeated manual workflow before revenue, qualification, customer service, reporting, or compliance should be considered for automation, delegation, simplification, or removal.
