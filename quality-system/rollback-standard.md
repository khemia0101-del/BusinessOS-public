# Rollback Standard

## Purpose

Every external/system change needs a way to stop, revert, or contain it.

## Rollback Plan Must Include

- What changed.
- Where it changed.
- Who can revert it.
- Exact revert steps.
- Data backup or snapshot if needed.
- Stop condition.
- Monitoring signal.
- Customer/employee communication if needed.

## No Rollback Means Higher Approval

If a change cannot be easily reverted, it requires stronger review and explicit owner/partner approval.
