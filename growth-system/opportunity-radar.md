# Opportunity Radar

## Purpose

Continuously detect high-leverage opportunities for growth, automation, simplification, and profit improvement.

## Sources

- Data room evidence.
- CRM data.
- Website analytics.
- Search Console.
- Ads platforms.
- Email/SMS metrics.
- Social/review platforms.
- Employee signals.
- Customer signals.
- Referral partner communications.
- Meetings/calls/emails.
- Financial statements.
- Support tickets.
- Sales calls.
- Competitor research.

## Opportunity Types

- More qualified leads.
- Faster lead response.
- Higher conversion.
- Better follow-up.
- More referral activity.
- New acquisition channel.
- SEO/content compounding.
- Paid acquisition tests.
- Social/reputation leverage.
- Customer retention.
- Cost reduction.
- Time savings.
- Software consolidation.
- Employee leverage.
- Error reduction.
- Compliance risk reduction.

## Scoring

Each opportunity should be scored:

| Factor | Meaning |
| --- | --- |
| Impact | Revenue, profit, time saved, risk reduced |
| Confidence | Evidence strength |
| Effort | Build and maintenance cost |
| Speed | Time to first result |
| Risk | Compliance, operational, customer, brand, data |
| Reversibility | Ease of rollback |
| Measurability | KPI clarity |

## Output Format
